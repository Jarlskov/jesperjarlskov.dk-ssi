Even though July was a pretty quiet month online due to everybody being on vacation, I still came across some interesting articles.

Earlier in the year, there was a big discussion in the PHP community after some people suggested that pretty much everything in your code was cruft, and that code should be as concise as possible. One argument for being the opposite is to <a href="https://www.thecodingmachine.com/type-hint-all-the-things/">type-hint all the things</a> which present an argument for how type hinting reduces the cognitive load of reading code.

In security training, Brute Logic presents <a href="https://brutelogic.com.br/blog/the-7-main-xss-cases-everyone-should-know/">The 7 main XSS cases everyone should know</a>.

We've recently moved our entire front-end build process at work to WebPack. This has very much been a black box to me, so I was happy to see WebPack core contributor Sean Larkin announce his new online course <a href="https://webpack.academy/p/the-core-concepts">WebPack the core concepts</a>.

Of course, there's also something Laravel related. First a tweet by Mohammed Said, subtlely announcing a nice new way for queue jobs in Laravel to determine whether they should actually go to the queue.

Matt Stauffer posed the question <a href="https://mattstauffer.co/blog/what-packages-do-you-install-on-every-laravel-application-you-create">What packages do you install on every Laravel application you create?</a>. The result is a list of interesting packages I'd recommend looking through. Most of them are not Laravel specific, so other PHP developers might find something interesting as well.
