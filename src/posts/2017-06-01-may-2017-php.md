The month of May is over, and as usual, it's time for a summary of interesting tech related articles I've found during the month.

We start out with some numbers. <a href="https://seld.be/about">Jordi Boggiano</a> published a new updated version of his <a href="https://seld.be/notes/php-versions-stats-2017-1-edition">PHP version stats</a>. A range of stats on the PHP version usage, based on the install stats on <a href="https://packagist.org/">packagist.org</a>. This does not comprise the full worldwide PHP usage, but provides some nice insights on the current trends.

On a meta-programming note, Robert Basic posted an article about how <a href="https://robertbasic.com/blog/open-source-taught-me-how-to-work-with-legacy-code/">open source taught him to work with legacy code</a>. It provides some nice points about working with legacy code and the thoughts of the people who came before you.

DHH posted an interesting view on his <a href="https://m.signalvnoise.com/programming-with-a-love-of-the-implicit-66629bb81ee7">love of the implicit parts of programming</a>. A nice piece about questioning common assumptions and defining best practices around your actual context, instead of expecting the same best practices to be the best in every circumstance.

On the geeky side, I really enjoyed a Stack Overflow response explaining <a href="https://stackoverflow.com/a/1180880/2217294">the difference between language constructs and built-in functions</a>. It is not knowledge that is useful in a programmer's day-to-day life, but it's always good to know more about how your tools actually work.
