<a href="http://compadre.dk">Sbc</a> har på sin blog skrevet en række indlæg, hvori han gennemgår <a href="http://ubuntudanmark.dk">Ubuntu Danmark</a>'s historie, som den i grove træk har set ud fra starten, og frem til nu.
Hovedfokus ligger på de konferencer vi har deltaget i, samt de release parties vi har afholdt.
<ul>
<li>I <a href="http://compadre.dk/blog/2009/11/03/ubuntu-i-danmark-del-1-af-5/">første afsnit</a> fortæller han hvordan det hele startede. LoCo'et blev oprettet, samt det første arrangement med deltagelse fra Ubuntu Danmark, samt om det første Ubuntu release party på dansk jord.</li>
<li>I <a href="http://compadre.dk/blog/2009/11/04/ubuntu-i-danmark-del-2-af-5/">andet afsnit</a> bliver det officielle LoCo-team godkendt, og der afholdes flere release parties.</li>
<li>I <a href="http://compadre.dk/blog/2009/11/05/ubuntu-i-danmark-del-3-af-5/">tredje afsnit</a> bliver der pludselig tale om en officiel dansk forening, men bestyrelse og penge i kassen.  Desuden bliver <a href="http://jesperjarlskov.dk/gratis-software-det-er-der-penge-i/">Ubuntu Danmark nævnt i medierne</a>. </li>
<li>I <a href="http://compadre.dk/blog/2009/11/06/ubuntu-i-danmark-del-4-af-5/">fjerde afsnit</a> begynder udgivelsesfesterne virkelig at vokse i omfang.</li>
<li>I <a href="http://compadre.dk/blog/2009/11/07/ubuntu-i-danmark-del-5-af-5/">femte og sidste del</a> nævnes nogen af de nyeste tiltag, såsom vores <a href="http://jesperjarlskov.dk/ubuntu-dk-f%c3%b8rste-podcast//">Ubuntu-dk podcast</a>, og hvordan dette bl.a. er blevet brugt til <a href="http://jesperjarlskov.dk/open-source-days-community-days-09-recap-og-podcast//">Open Source Days Community Days interviews</a>.</li>
</ul>
Det er en sjov lille gennemgang af hvordan foreningen har udviklet sig til det vi ser idag. Det er ret sjovt at se tilbage på den måde, og få opfrisket minder, og høre lidt om hvad der skete "før min tid". Bestemt en læsning værd!

Billedet øverst er forresten taget på Open Source Days 09 Community Days, og forestille (fra venstre): jlouis, mig, Søren, Peter Toft &amp; Niels Kjøller. Det er tyvstjålet fra <a href="http://www.version2.dk/artikel/12611-osd09-og-vi-fejlede-kun-lidt--del-33">Peter Tofts Version2 blog</a>.
