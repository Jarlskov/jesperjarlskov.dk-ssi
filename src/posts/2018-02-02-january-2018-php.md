It's a new year, but the tech scene doesn't show any signs of slowing down and January has been yet another fast paced interesting month.

<h2>Explainshell</h2>
We start out with a handy little tool for those of us with just enough command-line-fu to be dangerous, but not enough to be really productive without the help of StackOverflow. <a href="https://explainshell.com/" target="_blank">Explainshell.com</a> is a nice little tool that explains what happens in every part of a command line command. This is the least you could do before pasting random commands from StackOverflow into your terminal.

<h2>17 composer tips</h2>
I've previously talked about the wonders of the PHP dependency manager <a href="https://jesperjarlskov.dk/composer/" target="_blank">Composer</a>. Earlier this month Martin Hujer shared <a href="https://blog.martinhujer.cz/17-tips-for-using-composer-efficiently/" target="_blank">17 Tips for Using Composer Efficiently</a> to help you up your Composer game.

<h2>Harvesting credit card numbers</h2>
Everybody who works at least peripherally with security knows that security is hard. That doesn't make it any less important, though. David Gilbertson tells the (maybe true, maybe not) story of how he exploits weak website security and ubiquitous npm packages for <a href="https://hackernoon.com/im-harvesting-credit-card-numbers-and-passwords-from-your-site-here-s-how-9a8cb347c5b5" target="_blank">harvesting credit card numbers and passwords</a> from insecure websites.

<h2>Spectre & Meltdown</h2>
A new year means new security holes (YAY!). 2018 decided to not beat around the bush, and just start off with a massive security hole affecting most CPUs in use across the world. To make matters better, it even included 2 flaws. The 2 flaws was discovered by people working at <a href="https://googleprojectzero.blogspot.dk/" target="_blank">Google's Project Zero</a> in collaboration with a bunch of other security researchers has been named <a href="https://spectreattack.com/" target="_blank">Spectre and Meltdown</a>.

<h2>A faster Firefox</h2>
For the last while, the Firefox team has had a heavy focus on improving the browser's performance starting with <a href="https://medium.com/mozilla-tech/a-quantum-leap-for-the-web-a3b7174b3c12/" target="_blank">Firefox Quantum</a>. A new post on the Mozilla Hacks blog dives into the geeky side of how <a href="https://hacks.mozilla.org/2018/01/making-webassembly-even-faster-firefoxs-new-streaming-and-tiering-compiler/" target="_blank">Firefox speeds up WebAssembly</a>.
